Missing Semantic Landmarks

No <main>, <nav>, or <header> elements. Only <footer> uses a landmark. Screen readers rely on landmarks for navigation. Without them, the page is an undifferentiated block of text.

FIX: Wrap all sections in <main>. Add <nav> inside the hero or as a sticky bar. Add <header> role to the hero section.
P0

No Skip-to-Content Link

Keyboard users must tab through every link in the hero and footer before reaching main content. A skip link is the first element keyboard users encounter — it's non-negotiable for WCAG compliance.

FIX: Add visible-on-focus skip link as first child of <body>: "Skip to main content" → #main.

prefers-reduced-motion Ignored

Tech-card fade-up animations fire unconditionally. Users with vestibular disorders experience discomfort from motion they can't control. Every animation must respect the OS-level preference.

FIX: Wrap @keyframes tech-card-enter in @media (prefers-reduced-motion: no-preference). Remove animation class when preferred.

Global outline set to outline-ring/50 (oklch 0.556 at 50% opacity). On dark card backgrounds at oklch 0.205, this produces a barely-perceptible ring. Keyboard users cannot see where they are.

FIX: Change to outline-2 outline-ring with outline-offset-2 for 3:1 contrast on all surfaces.
