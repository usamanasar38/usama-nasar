// PRIORITY ISSUES
P0

Systemic Contrast Failure on Body Copy

muted-foreground at oklch(0.52 0.01 80) on background oklch(0.13 0.004 80) = 3.17:1. On card bg oklch(0.17 0.005 80) = 2.59:1 (project descriptions). WCAG AA requires 4.5:1 for text-sm and smaller. These are not edge cases — they affect every paragraph and every card on the page.

FIX: Bump muted-foreground to oklch(0.6 0.01 80) for body text on background. Use oklch(0.68 0.005 80) for text on card surfaces. Target 4.5:1 minimum.
P1

Uniform Section Rhythm Feels Flat

All six sections use mono-label → 3xl-heading → content. No section has a distinct structural identity. The page reads as a flat list rather than a paced portfolio with highlights and quieter moments.

FIX: Give one section a different background treatment (alternate bg). Vary the heading pattern in at least one section. Add section dividers that echo the hero's amber line.
P1

Tech Stack Lacks Categorization

20 skills in a flat wrapping list with no grouping. A hiring manager scanning for "React experience" or "testing familiarity" has no visual landmarks. Categories would add scan-ability and convey engineering depth.

FIX: Group skills into categories: Languages, Frameworks & Libraries, Testing & CI, Tools. Add small category labels between groups.
P2

Company Names Lack Visual Distinction

Company names in experience items are rendered in the same muted-foreground as body copy. "Rehani Soko", "Love Bonito", "Contrive Solutions" should carry more visual weight as brand names that hiring managers recognize.

FIX: Use font-semibold for company names, or a distinct color treatment. Separate company from location visually.
P2

Full-Card Links Block Text Selection

Project cards are wrapped in <a> tags, making the entire card a link. Users cannot select and copy project names, descriptions, or technology tags. This is hostile to the common recruiting workflow of copying text for notes.

FIX: Make only the project title the link. Wrap the card in a <div> and add a click handler, or restructure so the title link is the only interactive target.
